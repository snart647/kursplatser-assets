# kursplatser-assets

Public hosting for Snacka Snyggt weekly "kursplatser" story images (1080x1920 PNG).
These images are posted publicly to Instagram/Facebook stories — the repo only
pre-hosts them so the Meta Graph API can fetch a stable public URL.

Naming: `YYYY-Www.png` (ISO week of the Wednesday post), e.g. `2026-W34.png`.

URL form used by the scheduler:
`https://raw.githubusercontent.com/snart647/kursplatser-assets/main/YYYY-Www.png`

Pushed by the Monday approval flow in the (private) social-scheduler repo.
